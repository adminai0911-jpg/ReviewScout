## Kaufratgeber: Worauf müssen Sie achten?

Wenn Sie eine Kamera für ein Waldgrundstück kaufen, sollten Sie nicht auf den Preis allein schauen. Achten Sie auf diese vier Faktoren:

1. **Energieversorgung:** Solar ist Pflicht. In einem Wald gibt es keinen Strom. Achten Sie darauf, dass das Solarpanel möglichst effizient ist.
2. **Konnektivität:** Da meist kein WLAN verfügbar ist, sind Kameras mit SIM-Karten-Slot (4G/LTE) die einzige Möglichkeit für Live-Benachrichtigungen auf Ihr Handy.
3. **Robustheit:** Das Gehäuse muss zwingend nach IP66 oder höher zertifiziert sein. Achten Sie zudem auf die Betriebstemperatur, da Wälder im Winter extrem kalt werden können.
4. **Aufzeichnungsart:** Suchen Sie eine Kamera, die Bewegungsereignisse direkt auf einer SD-Karte speichert oder in eine Cloud hochlädt, falls die Kamera gestohlen wird.
